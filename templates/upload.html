What happens when you upload?

  1. Your file is encrypted before it is stored
  2. A cryptographic hash (SHA-256) is generated for integrity verification
  3. The encrypted file is stored in the configured database (local or cloud)
  4. Metadata is logged in the audit trail
  5. The paper is locked until the exam date/time you specify
  6. Only authorized reviewers can approve the paper
  7. Only authorized exam officers can release it
